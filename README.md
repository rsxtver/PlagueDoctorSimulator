# Plague Doctor Simulator (Roblox)

## Установка в Roblox Studio (одна вставка)

1. Откройте место в Roblox Studio, включите **View → Command Bar**.
2. Скопируйте **весь** файл [`Install.luau`](Install.luau), вставьте в Command Bar, нажмите **Enter**.
3. Все папки, парты и скрипты появятся в Explorer. Отмена — `Ctrl+Z`.
4. Один раз: **Game Settings → Security → Enable Studio Access to API Services** (нужно для DataStore).

Повторный запуск безопасен: создаётся только недостающее, код скриптов обновляется до актуального.

В неопубликованном месте DataStore недоступен — тогда в Studio игра работает без сохранений (в Output будет предупреждение).

## Что уже есть

- **Этап 1** — сохранение данных (DataStore), leaderstats.
- **Этап 2** — основной цикл: в деревне ходят заражённые жители, клик по ним лечит и наполняет маску миазмами
  (+бонус за полное исцеление, счётчик «Спасено»). Полную маску несите на зелёную площадку **Аптеки** — миазмы
  меняются на золото. HUD: золото, шкала маски, подсказки и всплывающие сообщения.
- **Апгрейды** — кнопка «Улучшения» (или клавиша E): Маска (вместимость), Ланцет (сила лечения),
  Плащ (скорость ходьбы). Покупку проверяет сервер.

- **Новая эпидемия** (перерождение) — от 500 золота: сбрасывает золото, миазмы и апгрейды,
  даёт Чумной череп и +50% золота в Аптеке навсегда (за каждое перерождение).

Все числа баланса — в `ReplicatedStorage.Shared.GameConfig`.

## Для продвинутых: Rojo

```bash
rojo serve
```

Проект описан в `default.project.json`, код лежит в `src/`.

## Для разработки

`Install.luau` генерируется из `default.project.json` и `src/`:

```bash
python3 tools/build_installer.py
```
