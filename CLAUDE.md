# Plague Doctor Simulator — инструкции для Claude

Roblox-симулятор на Luau. Общение с пользователем — на русском, пользователь новичок в Studio:
объясняй коротко и по шагам.

## Роль и правила кода

- Ты Senior Roblox Developer / геймдизайнер жанра Simulator.
- Только современный Luau: `task.wait/spawn/delay`, а не `wait()/spawn()`; типизация где полезно.
- Строго FilteringEnabled: валюта, покупки, проверки, сохранения — **только на сервере**.
  Клиент — ввод, эффекты, UI. Никогда не доверяй значениям от клиента; ограничивай частоту RemoteEvent.
- Работаем по этапам: одна механика за раз, после этапа — показать результат и ждать подтверждения.
- В ответе для каждого скрипта указывай тип (`Script`/`LocalScript`/`ModuleScript`) и путь в Explorer.

## Как работаем со Studio

Studio подключён через MCP-сервер `Roblox_Studio` (`.mcp.json`). Порядок работы над этапом:

1. Пиши код в `src/` (это источник правды, структура — в `default.project.json`).
2. Перегенерируй установщик: `python3 tools/build_installer.py`.
3. Примени в Studio: запусти мост `python3 tools/studio_bridge.py . <dump-dir>` (фоном) и выполни
   `tools/studio_sync.luau` через `execute_luau` (Edit) — Studio сам скачает и выполнит `Install.luau`
   (идемпотентен, «обновлено 0» = Studio совпадает с репозиторием). POST на `/dump/<name>` сохраняет
   файл в dump-dir — так выгружаются модели (`SerializationService` → `assets/Models.rbxm`).
4. Проверь: `start_stop_play` → `get_console_output` (ищи ошибки/warn) → останови плейтест.
   Для сложных сценариев — `subagent` типа `playtest`, `screen_capture`.
5. Коммить и пушь в `main` (git), кратко отчитайся пользователю.

GUI: не ставь кнопки в правый верхний угол экрана — там таблица игроков Roblox (CoreGui),
она перехватывает клики. Окна делай с размером в долях экрана (Studio-вьюпорт и телефоны маленькие).

Наименования файлов: `*.server.luau` → Script, `*.client.luau` → LocalScript, `*.luau` → ModuleScript.

## Архитектура

- `ServerScriptService/MainServer` (Script) — точка входа, вызывает `Init()` сервисов.
- `ServerScriptService/Services/*` (ModuleScript) — сервисы. Данные игрока меняет только `DataService`
  (`Get`, `WaitForData`, `Set`, `Increment`). Числовые поля данных зеркалятся в атрибуты игрока —
  клиент читает их для UI (`player:GetAttribute("Miasma")`).
- `ReplicatedStorage/Remotes` — RemoteEvent/RemoteFunction (создавать через проект/установщик).
- `ReplicatedStorage/Shared/GameConfig` — баланс (цены, апгрейды, питомцы).
- `ReplicatedStorage/Models` — 3D-модели (питомцы, яйцо), в git как `assets/Models.rbxm`;
  `Shared/Models.Build(name)` даёт копию. Модели из generate_procedural_model содержат Union-ы,
  поэтому хранятся бинарно, а не кодом.
- Переименовал/удалил объект — добавь старый путь в `OBSOLETE` в `tools/build_installer.py`,
  установщик уберёт его у тех, кто ставил прошлую версию.
- `Workspace/Zones/<Zone>/Infected` — заражённые NPC; `Pharmacy/SellPart` — зона продажи.

## Концепция

Чумной доктор лечит заражённых в средневековом городе. Цикл: клик по NPC → Миазмы в Маску
(вместимость = рюкзак) → Аптека: миазмы → Золото и Эликсиры → апгрейды и новые зоны →
Rebirth «Новая эпидемия» (сброс, множитель, Чумные черепа).

Апгрейды: Маска (вместимость), Инструмент (сила/скорость лечения), Плащ (скорость, защита),
Травы в клюве (пассивные бонусы). Зоны: Деревня → Рынок → Порт → Кладбище → Катакомбы →
Замок → Чумное измерение. Питомцы из яиц-склянок (ворон, крыса, летучая мышь, призрак,
чёрный кот), слияние в золотые/радужные. Позже: заражение игрока, алхимический стол,
волны эпидемии, ежедневки, лидерборд «Спасено жизней», коды, геймпассы.
Стиль: тёмный, но мультяшный (13+).

## План этапов (MVP)

1. ✅ DataService: leaderstats (Золото, Перерождения) + DataStore.
2. ✅ Клик по заражённым NPC → миазмы в маску (лимит вместимости), серверная проверка дистанции и кулдауна.
3. ✅ Аптека: продажа миазмов за золото.
4. ✅ 3 апгрейда (Маска, Инструмент, Плащ) + GUI.
5. ✅ Rebirth.
6. ✅ Питомцы (этап A): яйцо «Чумная склянка» (100 золота, в Деревне) → Ворон 50% x1.1, Крыса-фамильяр 30% x1.2,
   Летучая мышь 13% x1.5, Призрак 6% x2, Чёрный кот 1% x3. Надето до 3, инвентарь до 50, множители миазмов
   перемножаются с rebirth. Модели — generate_procedural_model/generate_mesh. Позиция питомцев — на клиенте,
   владение и множитель — на сервере. Анимация вылупления, GUI инвентаря «Надеть/Снять».
7. Ауры (этап B): ParticleEmitter + Attachment + PointLight. Зелёный туман (стартовая), Вороньи перья,
   Ядовитые пузыри, Призрачное пламя, Радужная чума. Источники: rebirth, «Ауро-склянка» за Эликсиры,
   позже VIP-аура за геймпасс. Надета одна, выбор и выдача на сервере, GUI выбора.
8. Анимированные персонажи (этап C): больные — R15-риги с idle/walk, бродят, кашляют, при выздоровлении
   выпрямляются, светятся и убегают. Взмах инструментом у доктора. Эффекты: «+N миазмов», частицы лечения,
   монеты в Аптеке.

Правило: каждую систему проверять на сервере, клиенту доверять только визуал. После этапа — плейтест,
коммит, пуш, короткий отчёт.
